# Términos de uso del modelo Laplace

Estos términos regulan **solo el modelo de pronóstico** de Laplace y lo que produce (probabilidades, goles esperados, marcadores y sus estimaciones). **No regulan el código del proyecto**, que se rige por su licencia (AGPL-3.0, ver `LICENSE`). Usar el modelo implica aceptarlos.

## 1. Qué es el modelo
Un modelo estadístico de fútbol: calcula **estimaciones de probabilidad** a partir de resultados pasados. No es un modelo de lenguaje y no ve alineaciones, lesiones, clima ni nada que no esté en sus datos. Una probabilidad no es una certeza: el resultado real puede y suele diferir.

## 2. Qué se puede hacer
- Usarlo para **estudio, investigación, uso personal y desarrollo** de herramientas propias.
- Citar sus pronósticos, indicando que son estimaciones del modelo Laplace y la fecha en que se calcularon.
- Entrenarlo con datos propios y compartir lo que se mida, indicando el origen de los datos.

## 3. Qué no se puede hacer
- Presentar sus pronósticos como **«seguros», «garantizados» o «sin riesgo»**, ni venderlos como tales.
- Usarlo para **captar, recibir o intermediar dinero de apuestas**, ni ofrecerlo como servicio de apuestas. Laplace **no es una casa de apuestas** y no recomienda apostar.
- Quitar o ocultar la advertencia de que son estimaciones cuando se muestran a otras personas.
- Presentarlo como una medición distinta de la que es: la evidencia publicada del proyecto indica que el modelo **supera a la tasa base pero no al mercado** donde hay cuotas.

## 4. Sin garantía
El modelo se ofrece **«tal cual»**, sin garantía de exactitud, disponibilidad ni adecuación a un fin. Quien lo usa asume las decisiones que tome con sus resultados. El autor no responde por pérdidas, daños ni decisiones basadas en el modelo.

## 5. No es consejo
Nada de lo que produce el modelo es consejo financiero, de apuestas ni de ningún otro tipo. Si se apuesta, es bajo responsabilidad propia y con las leyes del lugar donde se vive.

## 6. Datos de terceros
Este repositorio **no incluye** datos históricos ni modelos entrenados. Quien los obtiene por su cuenta debe respetar la licencia de cada fuente (algunas limitan el uso a particulares o prohíben usarlos para entrenar sistemas automáticos). Usar el modelo con esos datos es responsabilidad de quien los descarga.

## 7. Cambios
El modelo y estos términos pueden cambiar. La versión vigente es la del repositorio; las mediciones fechadas describen cómo se comportó el modelo ese día, no cómo se comportará.
